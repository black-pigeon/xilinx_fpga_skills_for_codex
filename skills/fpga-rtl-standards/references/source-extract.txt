2      L0: 命名规则
     ! 特殊说明：AXI等标准接口信号不受以下所有前缀规则约束（包括但不限于i , o , r , w , ri ,
      ro 等），应保持协议原生命名
     • 输入信号: 必须使用 i 前缀（如 i clk），此规则优先级最高（标准接口除外）
     • 输出信号: 必须使用 o 前缀（如 o data），此规则优先级最高（标准接口除外）
     • 寄存器: r 开头 (r counter)（优先级低于输入/输出信号，标准接口除外）
     • 连线: w 开头 (w enable)（优先级低于输入/输出信号，标准接口除外）
     • 寄存输入: ri 开头 (ri data valid)（标准接口除外）
     • 寄存输出: ro 开头 (ro result)（标准接口除外）
     • 参数/状态: P 开头 (P ST IDLE)
     • 数组: array结尾（建议格式如 w data array/r data array）
     • 跨时钟域: cdc 开头 ( xx cdc)
     • 使能控制的数据流: 必须采用 i xx data 和 i xx dvalid 格式（如 i dma data/i dma dvalid)

5     L3: 代码对齐规范
5.1    L3: 信号声明对齐


 1    //   位宽       /   信号名           / 分号   / 注释
 2    reg [7:0]         r_data         ;       // 数据寄存器
 3    reg               r_valid        ;       // 有效信号
 4    wire [31:0]       w_addr         ;       // 地址线


      规则说明：
       • 位宽对齐：[X:0] 统一缩进至相同列
       • 信号对齐：变量名起始位置对齐
       • 分号对齐：所有 ; 垂直对齐
       • 注释对齐：所有 // 垂直对齐，注释文本对齐


5.2    L3: 连续赋值对齐


 1    //       左值      / 等号       /    右值            / 分号       / 注释
 2    assign   o_data    =            r_data           ;         // 数据输出
 3    assign   o_valid   =            r_valid          ;         // 有效信号输出
 4    assign   o_ready   =            w_ready & ~i_busy;         // 组合逻辑输出
 5

 6    always @(posedge i_clk) begin
 7            r_A            <=        'd0                  ;      // 非阻塞赋值临近也需要对齐
 8            r_B            <=        'd0                  ;
 9    end


      规则说明：
       • assign 关键字：左对齐（所有 assign 起始列对齐）
       • 左值对齐：输出信号名起始位置对齐
       • 等号对齐：所有 = 垂直对齐
       • 右值对齐：表达式起始位置对齐（复杂表达式可右对齐）
       • 分号对齐：所有 ; 垂直对齐
       • 注释对齐：所有 // 垂直对齐，注释文本对齐

      • 当信号名超长时（超过20字符），允许：
           – 位宽对齐可适当放宽（如示例中 [63:0] 不严格对齐）

           – 超长信号名应控制在32字符内
           – 重要信号建议通过换行保持对齐
